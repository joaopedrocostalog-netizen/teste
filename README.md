# Palavras Cruzadas

Jogo de palavras cruzadas desenvolvido em HTML, CSS e JavaScript puro, pronto para uso no GitHub Pages.

## Recursos

- Grade interativa 10x10
- Dicas horizontais e verticais
- Seleção visual da palavra ativa
- Navegação por teclado
- Verificação de respostas
- Destaque de letras corretas e incorretas
- Cronômetro
- Contador de progresso
- Tela de conclusão
- Layout responsivo para computador e celular

## Publicação

O projeto inclui um workflow do GitHub Actions para publicação no GitHub Pages. No repositório, acesse **Settings → Pages** e selecione **GitHub Actions** como fonte caso ainda não esteja habilitado.
